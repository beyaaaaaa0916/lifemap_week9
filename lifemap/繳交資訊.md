# LifeMap 作業繳交資訊

> 發布完成後，請把下列 GitHub Repository 與網站連結更新為實際網址。

## 專案簡介

LifeMap 是一個繁體中文的人生願望探索地圖。我延伸自己之前製作的 LifeMap 網頁，讓使用者可以記錄願望、設定分類與目標日期、更新完成進度、寫下完成心得，也能搜尋篩選及匯出備份。本專案另外建立 `AGENTS.md`，將網站目的、版面風格、資料欄位、檔案結構和新增內容流程整理成明確規則。

## GitHub Repository

待 GitHub Pages 部署成功後填入：`https://你的帳號.github.io/lifemap/`

[`AGENTS.md`](AGENTS.md)

## AI 如何延續開發

未來新增願望分類或功能時，AI 可以先依 `AGENTS.md` 檢查資料格式、狀態代碼、分類圖示、表單與卡片呈現，再沿用奶油白與森林綠的視覺風格及既有單頁結構。文件也要求保留本機資料和 JSON 匯出、不將個人願望送到外部服務，並檢查搜尋、地圖、手機版與使用者輸入安全，讓新內容能融入原專案而不破壞既有功能。
